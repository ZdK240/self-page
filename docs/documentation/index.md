# An overview of my Work

## Fields

### Panoptes
-> PANOPTES (Panoptic Astronomical Networked Observatories for a Public Transiting Exoplanets Survey) is a 
citizen science project that aims to deploy compact robotic telescopes designed for continuous, high-precision 
photometry—measuring characteristics like light intensity and color. 

-> My role in this is as a speecialist in benchbuilding, where we train ourselves to repair or assemble a 
PANOPTES Unit without incurring the costs of either building a new unit or of taking apart an existing unit.

Additionally, I also have some experience in Image Stacking using software such as Siril, as well as in the
usage of Stellarium in order to find and target stars for viewing using the PANOPTES Units.

# Stellarium
<img width="447" height="512" alt="Stellarium_Splash" src="https://github.com/user-attachments/assets/d6f3c80a-f750-49cf-9726-cc0f4d3a0988" />

-> It is a free software that allows users to view the sky at various times of day from different locations.

It is easily modifiable, with possibilities of helping to visualize the view of a certain section of the sky 
from different telescopes and eyepieces, as well as visualizing the visibility of stars in the night sky with
different levels of light pollution.

This document, apart from giving an idea on what it is capable of, is also for the purpose of giving an idea on what the most commonly used tools in Space and Tech as a whole are used for, and how you can use them.


## Installation
-> The installation process is very straightforward, as you directly go to the official Stellarium website ([link here](https://stellarium.org/)), select your OS, and install the zip file or installer depending on the content.
<img width="1366" height="766" alt="siril - Google Search - Google Chrome 7_28_2026 11_24_41 AM" src="https://github.com/user-attachments/assets/15233fa5-7989-4b5e-a8a7-109efaa128a5" />
After that, you either have to extract the files from the zip file, or run the installer and follow the instructions in order to install Stellarium in your computer.

-> If, for any reason, you cannot install Stellarium, you can use the web variant, but as far as my experience goes, there is not much functionality, being limited to the current time and location, with the only good thing being able to see what planets are up at night, and at what times. ## A deeper look at tools 1 and 2
### Location setting
-> This tool, as the name suggests, lets you set the location of the observer in the application so that you can visualize the sky at that particular location.<img width="1366" height="768" alt="Stellarium 26 2 7_28_2026 12_16_47 PM" src="https://github.com/user-attachments/assets/969662a3-6c31-4bd7-803f-dead6235cb80" />

## Finding RA and Dec
-> In PANOPTES or Space and Tech in general, we use the RA and Dec values to find the location of a certain object in the sky. The values serve as coordinates, and are used by telescopes, Stellarium, equatorial mounts like the ones used for PANOPTES Units, and other applications.
To find the values, you simply have to click on the celestial object you want to find the values for, and find the appropriate numbers on the left side where information is displayed. Then you convert the values to a preferred unit, and then you can use it in the applications that were detailed above.<img width="1366" height="768" alt="Stellarium 26 2 7_28_2026 12_44_46 PM" src="https://github.com/user-attachments/assets/0dc93e2e-2992-4f25-9a21-032d7dcfbc61" />
